# Splittr 💸

A simple web application for splitting expenses between multiple people.

Splittr calculates how much each person needs to pay or receive based on how much they originally spent.

## Features

- 👥 Supports multiple people
- 💰 Enter individual spending amounts
- 👤 Optional custom names for each person
- 📥 View how much each person should receive
- 📤 View how much each person should pay
- 💵 Transactions displayed with two decimal places
- 📱 Responsive and simple UI
- 🌙 Dark-themed interface

## How It Works

Suppose three people spend:

| Person | Spent |
|--------|------:|
| Abhi | ₹1000 |
| Rahul | ₹500 |
| Alex | ₹0 |

Splittr calculates each person's fair share and determines the transactions required between them.

You can switch between:

- **RECEIVE** — see money each person should receive
- **PAY** — see money each person should pay
